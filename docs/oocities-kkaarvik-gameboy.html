Gameboy Projects source code in RGBDS assembly

  • Universal learning remote - including Sony WebTV Keyboard decoding (GBC only). remote.zip
  • Dedicated Sony keyboard decoding - type on your GBC with this Infrared keyboard (GBC only). sony_kb.zip
  • IBM Keyboard - type on your GBC using an AT keyboard connected to the GBC's serial port (GBC only) . ibm_kb.zip
  • RS232 - Talk at 9600,n,8,1 (actually lots of stop bits!) out/in the GBC serial port (GBC only). rs232.zip
  • N64 controller with rumble pak support (Thanks to Stephan Hans for rumble info!) note: this WILL NOT WORK on the Color GB. Read the controller and make it rumble with your GB (GB mono only). n64contr.zip
  • StopWatch. Time up to 99 hrs 59 min 59.99 sec and save 99 lap/split times to memory. stopwtch.zip
  • GBSoundXperimenter by MJCulross. With this ROM running on your GB you'll be able to figure out what all the sound registers do (at least I was able to). I added a different keypad routine (save some wear on your thumbs) and I added a routine to save to cart ram. (Posted with permission from the author).Soundxk.zip
  • Infrared Investigator - Use your GBC to "see" what information is coming out of your collection of infrared remote controls (GBC only).

Note: All include files come from Jeff Frohwein's GameBoy Dev'rs web pages.

PIC16F84 Projects

  • Nintendo 64 controller and 8-bit parallel interface to Gameboy (or anything else with a few changes).Gameboy source in GBDK C N64.zip
  • Boot up your GB or GB Colour with your own logo using a pic to toggle memory banks on power up. logo.zip I was able to open up a MegaMem cartridge (made by Datel) to see how they had been able to bypass Nintendo's logo - they used a PIC12C508 to toggle memory banks on power up. Damon Barwin and Alex Edge from Datel created the original device.
